# 上门服务预约系统 · 演示

一个可以直接在手机上点开的演示版：预约 → 派单 → 上门 → 计量 → 结算。

- **首页**：品类选择、行业切换（回收 / 家政 / 维修）
- **预约**：品类多选、数量、地址、时间、备注
- **订单**：状态流转、进度时间轴
- **后台**：订单池、一键派单、推进状态、导出 Excel（CSV）

## 关于这份演示

- 纯前端单文件（HTML + CSS + 原生 JS），无依赖、无后端、不联网
- 数据只存在浏览器 localStorage，刷新不丢，换设备就没了
- 正式版是微信小程序 + Node 后台 + MySQL，这套界面只是把流程跑给你看

## 本地打开

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8080
```

## 说明

界面里的价格、师傅、订单都是演示数据，不代表真实报价。
